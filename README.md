# Inteligência artificial EBAC

Trabalho para o módulo de IA da EBAC

## Proposta

Melhorar um código pré-definido, otimizando e comentando o mesmo para melhor legibilidade.

### Etapas

Eu criei um arquivo .py para o código original.
Eu inseri o seguinte prompt para otimizar o possível resultado de saída.

![Prompt](https://github.com/Talicatwolf/EBAC_IA/blob/main/images/1_etapa.png)

Após a IA modificar o código, as modificações, pontos de melhoria e as alterações foram respondidas sem perguntas extras com explicação bem detalhadas por conta do primeiro prompt.

![Prompt2](https://github.com/Talicatwolf/EBAC_IA/blob/main/images/2_etapa.png)

Após executar ambos os códigos, adicionei o módulo Time nos scripts para medir o tempo de execução de ambos.

Tempo de execução do original: 0.000285 segundos

Tempo de execução do otimizado: 0.000265 segundos
